# УУНиТ — Новости на высоте (React)

## Запуск
1. Установите Node.js LTS.
2. Откройте терминал в папке проекта.
3. Выполните:
   ```bash
   npm install
   npm run dev
   ```
4. Откройте URL, который покажет Vite (обычно http://localhost:5173).

## Структура
- `index.html` — точка входа.
- `src/main.jsx` — запуск React.
- `src/App.jsx` — страницы, фильтрация, реакции и предложка.
- `src/styles.css` — стили, адаптивность и анимации.

## Что есть
- Главная без блока «Популярное».
- Фильтрация новостей по факультетам/институтам и поиск.
- Теги каждой новости.
- Реакции самолётик, сердце и избранное.
- Предложка с отдельными полями: факультет/институт, курс 1–5, тип обучения (бакалавриат, магистратура, аспирантура, специалитет), рубрика, текст и теги. Поля аудитории необязательны.
- Очередь предложенных новостей: редактирование, отклонение и публикация в демонстрационную ленту.
- Экран входа/регистрации.
- Стартовая анимация самолётика.

Это frontend-демо: для настоящих аккаунтов, совместной модерации и постоянного хранения данных потребуется backend/API и база данных.

## Дополнительные возможности
- К предложению новости можно прикрепить до 3 медиафайлов (изображения, видео, аудио); есть предпросмотр и удаление вложения до отправки.
- После входа пользователь попадает в личный кабинет, где можно изменить аватар, имя, фамилию и почту.
- Демо-роли: студент, редактор и модератор. Студент работает со своими предложениями, редактор видит общую очередь и может редактировать, модератор может публиковать и отклонять предложения.
- Это прототип без backend: аккаунты, права и файлы не сохраняются на сервере. Выбор роли на клиенте не подходит для реальной авторизации; права необходимо проверять на backend.

## Дополнительные функции
- В предложении новости можно указать необязательную дату мероприятия.
- На опубликованной новости показывается дата мероприятия; если она не указана, используется дата публикации.
- Нажатие на реакцию ✈ создаёт уведомление-напоминание для вошедшего пользователя. Уведомления доступны через колокольчик и пункт «Уведомления».
- На странице редактуры у редактора и модератора есть кнопка «ИИ-помощник». Это демонстрационная заглушка с простыми рекомендациями, а не подключённая языковая модель.
- Уведомления и данные приложения хранятся в состоянии React и сбрасываются после перезагрузки; для постоянного хранения требуется backend.


## Последние изменения
- Список факультетов и институтов обновлён по официальной структуре УУНиТ: ИГСН, ИИМРТ, ИИГУ, ИП, ИПЧ, ИТМ, ИХЗЧС, ИНЭБ, ИЭТИ, ФТИ, ФАДЭТ, ФБФВиЖ, ФПИК, Передовая инженерная школа «Моторы будущего» и Военный учебный центр.
- Модератору доступна отдельная страница «Пользователи»: можно просматривать зарегистрированные в текущем демо-сеансе аккаунты и назначать роли студента, редактора или модератора.
- Если факультет, курс и тип обучения оставлены пустыми, предложение помечается как публичное и не ограничивается фильтром аудитории. При этом публикация по-прежнему доступна только модератору.
- У каждой новости есть отдельная страница подробного просмотра, открываемая по заголовку или кнопке «Читать новость полностью». Предложения можно открыть в режиме предпросмотра.
- Данные и роли пока существуют только в состоянии React и исчезают после перезагрузки. Для реального списка всех пользователей, безопасного назначения ролей и сохранения новостей необходим backend и база данных.
