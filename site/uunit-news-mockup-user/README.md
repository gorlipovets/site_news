# Новостная лента УУНиТ — макет на React

## Запуск
1. Установите Node.js (LTS).
2. Откройте терминал в папке проекта.
3. Выполните:
   ```bash
   npm install
   npm run dev
   ```
4. Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Файлы
- `index.html` — HTML-оболочка.
- `src/App.jsx` — React-компонент страницы и демонстрационная логика.
- `src/main.jsx` — точка входа React.
- `src/styles.css` — оформление, адаптивность и фиолетово-чёрная палитра.
- `package.json` — зависимости и команды запуска.

## Что работает в макете
- поиск по заголовкам и тексту;
- фильтр по факультетам/институтам;
- реакции-эмодзи с переключением;
- отдельная реакция «Я пойду» для события;
- сохранение новости в закладки в состоянии страницы;
- модальное окно «Предложить новость» и добавление демонстрационного поста;
- адаптивная верстка.

Данные хранятся только в состоянии браузерной страницы и сбрасываются при перезагрузке. Для настоящего сайта потребуются backend, база данных, авторизация, загрузка изображений и модерация новостей. Изображения загружаются с Unsplash, шрифт — с Google Fonts.
